# nvm CLI

`nvm.exe` manages Node.js installs, versions, configuration, cache, and related tools.

Browse the subcommands in the sidebar, or start with [`nvm install`](/command/nvm/install/) and [`nvm use`](/command/nvm/use/).

For the runtime shims that intercept `node`, package managers, and global CLIs in shim mode, see [node (shim)](/command/node), [Package Manager Shims](/command/package-manager-shims), and [Global Module Shims](/command/global-module-shims).
