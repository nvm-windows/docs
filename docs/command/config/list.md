# nvm config list

List effective NVM configuration values.

**Aliases:** `cfg list`, `cfg ls`

## Usage

```powershell
nvm config list [flags]
```

## Flags

| Flag | Short | Description |
|------|-------|-------------|
| `--json` | | Output all settings as JSON. |

## Examples

```powershell
nvm config list
nvm config list --json
```
