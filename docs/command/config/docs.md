# nvm config docs

Print built-in documentation for every configuration option.

## Usage

```powershell
nvm config docs [flags]
```

## Flags

| Flag | Short | Description |
|------|-------|-------------|
| `--json` | | Option metadata as JSON. |

## Examples

```powershell
nvm config docs
nvm config docs --json
```
