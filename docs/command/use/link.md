# nvm use link

Switch NVM to **link** operating mode.

## Usage

```powershell
nvm use link
```

## Arguments

This subcommand takes no arguments.

## Example

```powershell
nvm use link
```

## Sample output

```powershell
successfully switched to link mode
```

See [Operating Modes](../../introduction/modes).
