# nvm use shim

Switch NVM for Windows to **shim** operating mode.

## Usage

```powershell
nvm use shim
```

## Arguments

This subcommand takes no arguments.

## Example

```powershell
nvm use shim
```

## Sample output

```powershell
successfully switched to shim mode
```

See [Operating Modes](../../introduction/modes).
