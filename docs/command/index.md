# Command Reference

Command documentation for NVM for Windows v2:

| Section | Contents |
|---------|----------|
| [nvm](/command/nvm/) | `nvm.exe` CLI — install, use, list, config, cache, and related commands |
| [node (shim)](/command/node) | Runtime `node` shim flags (`--nvm-use`, `--nvm-which`, …) |
| [Package Manager Shims](/command/package-manager-shims) | `proxy.exe` for npm/npx/yarn/pnpm |
| [Global Module Shims](/command/global-module-shims) | `proxy.exe` hardlinks for global CLIs (`tsc`, …) |

Start with [`nvm install`](/command/nvm/install/) and [`nvm use`](/command/nvm/use/), or [Operating Modes](/features/modes) for shim vs link.
