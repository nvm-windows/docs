# About

[Node.js](https://nodejs.org) is not designed to run multiple different versions per computer. Modern workflows frequently depend on multiple versions though. In the earliest days of Node.js, developers continually reinstalled the versions they needed to test. Naturally, this was extremely time-consuming.

NVM for Windows manages multiple versions of Node.js per computer.
