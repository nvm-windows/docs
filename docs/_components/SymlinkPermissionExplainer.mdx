[Link mode](/features/modes#link-mode) uses an NTFS junction to select the Node.js version.

- NTFS junctions do not need a special privilege.
- NTFS junctions do not support UNC paths such as a network share or a mapped drive.

If Node.js storage uses a UNC path, NVM for Windows creates a symbolic link.
Windows requires the `SeCreateSymbolicLinkPrivilege` privilege to create that symbolic link.

:::tip[Enable `SeCreateSymbolicLinkPrivilege`]
- A user with administrative rights has this privilege.
- Windows gives this privilege when you enable **[Windows Developer Mode](https://learn.microsoft.com/en-us/windows/advanced-settings/developer-mode)**.
- You can also grant this privilege with Group Policy:<br/>
**Computer Configuration** > **Windows Settings** > **Security Settings** > **Local Policies** > **User Rights Assignment** > *Create symbolic links*.
:::
