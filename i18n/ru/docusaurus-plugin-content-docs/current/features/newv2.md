# Что нового в v2

## Обзор

*   **Без обязательных прав администратора**
*   **Современные рабочие процессы без symlink**
*   **Закрепление версий** — .nvmrc, .node-version, package.json или пользовательские файлы
*   **Более быстрые загрузки и установки**
*   **Автоустановка отсутствующих версий Node.js**
*   **Готовность для разработчиков и Enterprise**
*   **Полная переработка ради скорости и поддерживаемости** — Go и Zig
*   **Две сборки** — Community (MIT) и Certified (EULA)

:::info[Изменение подписи кода]
- Community-сборки не подписаны кодом.
- **Certified-сборки подписаны на 100%.**

Во всех подписях издатель — «Author Software Inc». Управление проектом передано Author Software Inc, но команда та же.
:::

## Community & Certified Builds

:::info[Certified Builds]
Доступно с сентября 2026.
:::

Community-сборка остаётся бесплатной и open-source (MIT). Certified-сборки добавляют подписанные установщики, опциональные **Trust Artifacts**, **Advanced Logging**, дополнение **Governance** и связанные элементы управления (см. [Выбор edition](../guide/builds/index.md)).

## Установка Node.js

- **Параллельные установки** — несколько версий Node.js одновременно
- **Меньший объём загрузок (40%)** — компактные архивы `.7z`
- **Нативная распаковка** — быстрее и с меньшей зависимостью от внешних unpacker
- **Локальные изолированные загрузки** — установка из локального каталога архивов офлайн или при ограничениях (см. [Локальные установки](./local-installations), [Изолированные установки](../guide/air-gapped-installations))
- **Кэширование** — переиспользование скачанных/распакованных ресурсов при повторных установках ([Кэш загрузок](./cache))

:::tip[7-zip]
Не обязателен, но NVM for Windows использует нативный 7-Zip для распаковки, если он установлен. Проприетарные алгоритмы 7-Zip дают максимальную скорость. [7-Zip бесплатен](https://www.7-zip.org).

Если 7-Zip недоступен, используется более медленный встроенный распаковщик.
:::

## Режимы работы

Главное функциональное изменение — [режимы работы](./modes).

- **Лёгкие shim**: shim на Zig для Node и связанных команд (npm, npx и т. д.)
- **Link mode с нулевой задержкой**: модель junction/symlink в PATH, когда перехват shim не нужен

Режим shim открывает переключение версий по каталогу и другую автоматизацию. **Link mode** остаётся для legacy-сценариев и обхода редких моделей прав из v1.

## Автоматизация

- **Переключение версии по каталогу** — выбор Node из текущего каталога (например, `.nvmrc`) в режиме shim ([Разрешение версий](../guide/version-resolution))
- **Автоустановка отсутствующих версий** — установка нужной версии, если проекту её ещё нет
- **Автоустановка глобальных модулей по умолчанию** — опционально заданный набор globals с каждой новой версией Node.js

## Настройки

- **Пользовательские алиасы** — алиасы версий через `nvm alias` ([команда alias](../command/alias/))
- **Пользовательские глобальные модули по умолчанию** — пакеты, ставящиеся с каждой новой версией ([`auto_installed_modules`](../cfg/core#downloads-and-mirrors))
- **Настройки реестра Windows** — пользовательские prefs и (в certified-сборках) политика машины через `nvm config` ([Базовая конфигурация](../cfg/core), [Справочник политики реестра](../cfg/registry))

## Нативные интеграции Windows

- **Windows Apps** — установленные версии Node.js в «Приложения и возможности» ([Интеграция с приложениями Windows](./windows-apps))
- **Windows Event Viewer** — операционные события в Event Viewer ([Журналирование событий](./log))
- **Desktop Notification Center** — обновления и уведомления в центре уведомлений Windows ([Уведомления на рабочем столе](./notifications))
- **Windows Registry** — пользовательские настройки в ключах реестра ([Интеграция с реестром Windows](./windows-registry))

## Безопасность и governance

_(дополнение Governance)_

- **Ограничение версий Node.js** — allow/block списки и политики firewall (например, блок EOL) ([Version Firewall + Author Mirror](./author-mirror))
- **Управление настройками NVM** — блокировка или переопределение prefs через ADMX / GPO / Entra ([Administrative Templates](../cfg/ad))
- **Расширенная поддержка прокси** — IWA (NTLM/Negotiate) и PAC/WPAD сверх базового HTTP proxy ([Зеркала загрузок](./mirrors#http-proxies))
- **Пользовательские зеркала Node.js** — зеркало Author с политиками (`mirror.author.io`) или другие одобренные зеркала ([Зеркала загрузок](./mirrors), [Version Firewall + Author Mirror](./author-mirror))
- **Интеграция Active Directory и Entra** — развёртывание/управление через AD и Intune ([Enterprise Deployment](../install/enterprise/requirements))

## Trust artifacts и observability

- **SBOM, provenance и VEX** _(дополнение Trust Artifacts)_ — материалы доверия цепочки поставок в релизных паках ([Выбор edition](../guide/builds/))
- **Полностью аудируемое нативное журналирование** _(дополнение Advanced Logging)_ — структурированные логи для SIEM/аудита ([Журналирование событий](./log), [Выбор edition](../guide/builds/))
