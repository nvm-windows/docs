Установленные версии Node.js видны на экране «Приложения» Windows. Их можно удалить прямо оттуда.

![1776491546067](/img/features/install/1776491546067.png)

ОС распознаёт каждую версию как полноценную «официальную» установку.

## Дополнительная ценность для кибербезопасности

Менеджеры версий традиционно работают с «теневыми установками»: Node.js лежит там, где его хранит менеджер версий. ОС не отличает его от любого другого файла — например, злонамеренного `node.exe`, имитирующего настоящий.

Показывая установки в системе, NVM for Windows помогает Windows отличать корректные установки от подделок.

Типичные сканеры вроде Qualys или CrowdStrike находят «официальные» приложения, включая версии Node.js, установленные NVM for Windows. Это даёт конкретные наборы данных для оценки уязвимостей. Поскольку каждая версия зарегистрирована в ОС, инструменты могут выявлять rogue-файлы, переименованные в node.exe, которых нет среди официальных установок. Так проще обнаружить malware, маскирующийся под Node.

NVM for Windows криптографически проверяет издателя исполняемого файла при установке, а аудит/антивирус Windows отслеживает попытки перезаписи файла. Режим shim NVM for Windows также проверяет node.exe при каждом запуске.
