# nvm config list

Список действующих значений конфигурации NVM.

**Псевдонимы:** `cfg list`, `cfg ls`

## Использование

```powershell
nvm config list [flags]
```

## Флаги

| Флаг | Краткий | Описание |
|------|---------|----------|
| `--json` | | Вывести все параметры в формате JSON. |

## Примеры

```powershell
nvm config list
nvm config list --json
```
