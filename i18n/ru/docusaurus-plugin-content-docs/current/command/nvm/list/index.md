# nvm list

Список установленных версий Node.js. Поведение по умолчанию при запуске `nvm list` без подкоманды.

**Псевдоним:** `ls`

## Использование

```powershell
nvm list [majors ...] [flags]
nvm list installed [majors ...] [flags]
```

## Подкоманды

| Подкоманда | Описание |
|------------|----------|
| *(по умолчанию)* / `installed` | Установленные версии — эта страница. |
| [`releases`](./releases) | Доступные для загрузки релизы с зеркал. |
| [`cached`](./cached) | Версии в кэше загрузок. |

## Аргументы

| Аргумент | Обязательный | Описание |
|----------|--------------|----------|
| `[majors ...]` | Нет | Числовые фильтры по мажорной версии (`18`, `20`). Именованные псевдонимы не принимаются. |

## Флаги

| Флаг | Краткий | Описание |
|------|---------|----------|
| `--json` | | Структурированный JSON с маркерами установленных, кэшированных и версии по умолчанию. |

Также применяется к [`releases`](./releases) и [`cached`](./cached): `--limit`, `--no-limit`.

## Примеры

```powershell
nvm list
nvm list installed
nvm list installed 18 20
nvm list --json
```

## Пример вывода

```powershell
* 24.1.0    (default)
  22.14.0
  20.19.1
```
