# CLI nvm

`nvm.exe` управляет установками Node.js, версиями, конфигурацией, кэшем и связанными инструментами.

Просматривайте подкоманды в боковой панели или начните с [`nvm install`](/command/nvm/install/) и [`nvm use`](/command/nvm/use/).

О runtime-shim для `node`, менеджеров пакетов и глобальных CLI в режиме shim см. [node (shim)](/command/node), [Package Manager Shims](/command/package-manager-shims) и [Global Module Shims](/command/global-module-shims).
