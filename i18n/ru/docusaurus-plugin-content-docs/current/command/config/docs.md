# nvm config docs

Вывести встроенную документацию для каждого параметра конфигурации.

## Использование

```powershell
nvm config docs [flags]
```

## Флаги

| Флаг | Краткий | Описание |
|------|---------|----------|
| `--json` | | Метаданные параметров в формате JSON. |

## Примеры

```powershell
nvm config docs
nvm config docs --json
```
