# nvm on

Включить управление Node.js через NVM.

## Использование

```powershell
Usage: nvm on
```

## Аргументы

Эта команда не принимает аргументов.

## Флаги

У этой команды нет флагов.

## Поведение

| Шаг | Деталь |
|-----|--------|
| Настройка link | Конфигурация цели `.nodejs` с учётом режима |
| Режим link | Восстанавливает цель link при наличии активной версии |
| Режим shim | Выполняет обновление shim после активации |
| Настройки | Устанавливает [`enabled=true`](../cfg/core#related-settings) |

## Пример

```powershell
nvm on
```

## Пример вывода

```powershell
NVM for Windows is now managing Node.js installations.
```

## Проверенная расшифровка (локальный запуск)

```powershell
PS> nvm on --help
Usage: nvm on

Manage Node.js with nvm.
```

## Типичные сценарии

- Повторное включение управления после временного `nvm off`
- Восстановление ожидаемых ссылок после ручных изменений пути или link

Используйте после обслуживания, устранения неполадок или временной приостановки через `nvm off`.
