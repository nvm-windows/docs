# Справочник команд

Документация по командам NVM for Windows v2:

| Раздел | Содержание |
|--------|------------|
| [nvm](/command/nvm/) | CLI `nvm.exe` — install, use, list, config, cache и связанные команды |
| [node (shim)](/command/node) | Флаги runtime-shim `node` (`--nvm-use`, `--nvm-which`, …) |
| [Package Manager Shims](/command/package-manager-shims) | `proxy.exe` для npm/npx/yarn/pnpm |
| [Global Module Shims](/command/global-module-shims) | hardlink `proxy.exe` для глобальных CLI (`tsc`, …) |

Начните с [`nvm install`](/command/nvm/install/) и [`nvm use`](/command/nvm/use/) или с [Режимов работы](/features/modes) (shim vs link).
