# nvm use link

Переключение NVM в режим работы **link**.

## Использование

```powershell
nvm use link
```

## Аргументы

Эта подкоманда не принимает аргументов.

## Пример

```powershell
nvm use link
```

## Пример вывода

```powershell
successfully switched to link mode
```

См. [Режимы работы](../../features/modes).
