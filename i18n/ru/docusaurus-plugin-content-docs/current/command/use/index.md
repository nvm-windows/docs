# nvm use

Переключение версии Node.js по умолчанию.

## Использование

```powershell
nvm use <version> [flags]
```

Подкоманда по умолчанию, когда вы передаёте версию напрямую (например, `nvm use 24`).

## Подкоманды

| Подкоманда | Описание |
|------------|----------|
| *(по умолчанию)* | Установка активной версии — эта страница. |
| [`lts`](./lts) | Использовать последний LTS или именованную линейку LTS. |
| [`latest`](./latest) | Использовать наивысшую semver среди установленных версий. |
| [`last`](./last) | Использовать ранее активную версию по умолчанию. |
| [`shim`](./shim) | Переключиться в режим работы shim. |
| [`link`](./link) | Переключиться в режим работы link. |

## Аргументы

| Аргумент | Обязательный | Описание |
|----------|--------------|----------|
| `<version>` | Да | [Спецификатор версии](../../guide/version-resolution). Может выполнить установку при отсутствии версии, если не задан `--local`. |

## Флаги

| Флаг | Краткий | Описание |
|------|---------|----------|
| `--install` | `-i` | Установить запрошенную версию, если она отсутствует. Переопределяет [`auto_install=false`](../../cfg/core#project-detection-and-auto-behavior). |
| `--no-install` | `-n` | Не устанавливать, если версия отсутствует. Переопределяет [`auto_install=true`](../../cfg/core#project-detection-and-auto-behavior). |
| `--local` | `-l` | Использовать последнее **установленное** совпадение для частичной версии. Никогда не устанавливает. |

## Примеры

```powershell
nvm use 24
nvm use 24.2.0 --install
nvm use 24 --no-install
nvm use 24 --local
```

## Пример вывода

```powershell
Now using Node.js v24.1.0 by default.
```

## Примечания

- Сохраняет текущую версию по умолчанию и обновляет `last_version`.
- В режиме shim после активации выполняется reshim.
- В режиме link `.nodejs` указывает на связанный путь активной среды выполнения.
