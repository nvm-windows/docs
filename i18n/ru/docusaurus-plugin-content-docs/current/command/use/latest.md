# nvm use latest

Использовать наивысшую семантическую версию среди **установленных** версий (не самый новый удалённый релиз).

## Использование

```powershell
nvm use latest
```

## Аргументы

Эта подкоманда не принимает аргументов.

## Пример

```powershell
nvm use latest
```
