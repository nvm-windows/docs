# nvm use shim

Переключение NVM в режим работы **shim**.

## Использование

```powershell
nvm use shim
```

## Аргументы

Эта подкоманда не принимает аргументов.

## Пример

```powershell
nvm use shim
```

## Пример вывода

```powershell
successfully switched to shim mode
```

См. [Режимы работы](../../features/modes).
