# nvm use last

Вернуться к ранее активной версии по умолчанию.

## Использование

```powershell
nvm use last
```

## Аргументы

Эта подкоманда не принимает аргументов.

## Пример

```powershell
nvm use last
```

## Примечания

Завершается сообщением об ошибке, если в настройках не сохранена предыдущая версия по умолчанию.
