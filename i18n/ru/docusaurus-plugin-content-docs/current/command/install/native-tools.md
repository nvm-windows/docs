# nvm install native-tools

Запуск `install_tools.bat` из самой новой установленной версии Node.js, которая его содержит.

Это необходимо только для компиляции нативных модулей.

:::warning[Большая загрузка]
Эта утилита часто устанавливает большие файлы (3 ГБ и более), альтернативные установщики (например, chocolatey) и другие среды выполнения (например, Python). Этот текстовый скрипт поставляется вместе с Node.js. NVM for Windows не проверяет его.
:::

:::tip[Рекомендация]
Отключите эту функцию в регулируемых средах.
:::

## Использование

```powershell
nvm install native-tools
```

## Аргументы

Эта подкоманда не принимает аргументов.

## Флаги

У этой подкоманды нет флагов.

## Поведение

| Деталь | Описание |
|--------|----------|
| Политика | Заблокировано, когда [`allow_tool_install`](../../cfg/registry#available-registry-keys) отключён. |
| Обнаружение | Завершается ошибкой, если ни одна установленная версия не содержит `install_tools.bat`. |
| Выполнение | Запускается через `cmd.exe` в обнаруженном каталоге инструментов. |

## Пример

```powershell
nvm install native-tools
```
