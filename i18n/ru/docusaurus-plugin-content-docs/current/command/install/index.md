# nvm install

Установка одной или нескольких версий Node.js.

**Псевдонимы:** `i`, `add`

## Использование

```powershell
nvm install <version> [<version> ...] [flags]
```

Подкоманда по умолчанию, когда вы передаёте аргументы версии напрямую (например, `nvm install 24`).

## Подкоманды

| Подкоманда | Описание |
|------------|----------|
| *(по умолчанию)* | Установка одной или нескольких версий — эта страница. |
| [`native-tools`](./native-tools) | Запуск `install_tools.bat` из самой новой подходящей установки. |

## Аргументы

| Аргумент | Обязательный | Описание |
|----------|--------------|----------|
| `<version> ...` | Да | Один или несколько [спецификаторов версии](../../guide/version-resolution). |

## Флаги

| Флаг | Краткий | Описание |
|------|---------|----------|
| `--copy-from` | | Копировать глобальные модули из существующей установленной версии при установке. |
| `--from` | | Установить глобальные модули по списку модулей другой установленной версии. |
| `--cache` | | Сохранить загруженные артефакты в кэш для повторного использования. |
| `--no-cache` | | Установка без кэширования (если не применяется политика или источник только локальный). |
| `--force` | | Переустановить, даже если целевая версия уже существует. |
| `--insecure` | | Принимать недействительные TLS/SSL-сертификаты от источников загрузки. Используйте только в контролируемых сетях. |

Внутренние флаги (`--notify`, `--debug`) предназначены для автоматизации и скрыты из обычного вывода справки.

## Примеры

```powershell
nvm install lts
nvm install 24
nvm install 22.14.0 20.19.1
nvm install lts/iron
nvm install 24 --cache
nvm install 24 --no-cache
nvm install 24.0.0 --force
nvm install 24 --copy-from=22.14.0
nvm install 24 --from=22.14.0
```

## Пример вывода

```powershell
Installing Node.js v24.1.0...
Downloading node-v24.1.0-win-x64.7z...
Extracting files...
Installed Node.js v24.1.0
```

## Примечания о поведении

- Если настроен [`local_dir`](../../cfg/registry#available-registry-keys), установки используют это расположение как корень источника/кэша.
- Если включён [`local_install_only`](../../cfg/registry#available-registry-keys), установки ограничены локальными источниками.
- Список автоматически устанавливаемых модулей ([`auto_installed_modules`](../../cfg/core#downloads-and-mirrors)) применяется во время установки.

См. также [Локальные установки](../../features/local-installations), [Установки без доступа к сети](../../guide/air-gapped-installations), [nvm cache](../cache/) и [nvm use](../use/).
