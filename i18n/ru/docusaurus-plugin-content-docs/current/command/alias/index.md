# nvm alias

Управление именованными псевдонимами для версий Node.js.

## Использование

```powershell
Usage: nvm alias <command>
```

## Подкоманды

| Подкоманда | Псевдонимы | Описание |
|------------|------------|----------|
| [`add`](./add) | — | Добавить или обновить псевдоним (по умолчанию при наличии аргументов). |
| [`list`](./list) | `ls` | Список псевдонимов. |
| [`remove`](./remove) | `rm` | Удалить один или несколько псевдонимов. |

## Зарезервированные имена

| Имя | Примечания |
|-----|------------|
| `default`, `current`, `latest`, `lts`, `last` | Встроенная семантика команд |
| `daily`, `alpha`, `beta`, `prerelease` | Зарезервировано для будущего использования |
| `link`, `shim` | Имена режимов работы |
| `lts/*` | Зарезервированное пространство имён LTS (например, `lts/iron`) |

## Примечания

- Цели псевдонимов нормализуются до конкретных версий при добавлении.
- Используйте канонические строчные имена псевдонимов для согласованности.
