# nvm alias add

Добавление или обновление именованного псевдонима для версии Node.js.

## Использование

```powershell
nvm alias add <name> <version> [flags]
```

## Аргументы

| Аргумент | Обязательный | Описание |
|----------|--------------|----------|
| `<name>` | Да | Имя псевдонима. Не может содержать пробелы или использовать зарезервированные имена. |
| `<version>` | Да | Целевой [спецификатор версии](../../guide/version-resolution) для разрешения и сохранения. |

## Флаги

| Флаг | Краткий | Описание |
|------|---------|----------|
| `--silent` | `-s` | Подавить интерактивный запрос переопределения, если псевдоним уже существует. |

## Примеры

```powershell
nvm alias add legacy 18.20.8
nvm alias add legacy 20.19.1 --silent
nvm use legacy
```

## Пример вывода

```powershell
"legacy" now refers to v20.19.1
```
