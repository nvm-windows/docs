[Режим link](/features/modes#link-mode) использует NTFS junction, чтобы выбрать версию Node.js.
NTFS junction не требует особой привилегии.
NTFS junction не поддерживает UNC-путь (сетевой ресурс или подключенный диск).

Если хранилище Node.js использует UNC-путь, NVM for Windows создаёт символическую ссылку.
Windows требует привилегию `SeCreateSymbolicLinkPrivilege`, чтобы создать эту символическую ссылку.

:::tip[Включение `SeCreateSymbolicLinkPrivilege`]
- У пользователя с правами администратора эта привилегия есть.
- Windows выдаёт эту привилегию, когда вы включаете **[режим разработчика Windows](https://learn.microsoft.com/ru-ru/windows/advanced-settings/developer-mode)**.
- Эту привилегию также можно выдать групповой политикой:<br/>
**Конфигурация компьютера** → **Параметры Windows** → **Параметры безопасности** → **Локальные политики** → **Назначение прав пользователя** → *Создание символьных ссылок*.
:::
