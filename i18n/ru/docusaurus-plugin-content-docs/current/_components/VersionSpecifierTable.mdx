| Форма | Пример | Разрешение |
|------|---------|------------|
| Последний релиз | `latest` | Новейший доступный релиз из индекса зеркала. |
| Последний LTS | `lts` | Новейший доступный LTS-релиз. |
| Именованная LTS-линейка | `lts/iron` | Новейший релиз из указанной LTS-линейки. |
| Пользовательский alias | `legacy` | Версия, назначенная через [`nvm alias add`](../command/alias/add). |
| Только major | `24` | Новейший релиз вида `24.x.x`. |
| Major.minor | `24.1` | Новейший релиз вида `24.1.x`. |
| Точная версия | `24.1.0`, `v24.1.0` | Указанный релиз. Префикс `v` необязателен. |
