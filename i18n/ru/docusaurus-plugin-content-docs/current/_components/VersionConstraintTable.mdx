| Ограничение | Пример | Значение |
|------------|---------|---------|
| Caret | `^18` | Совместимо с major 18. |
| Tilde | `~20.1` | Совместимо с minor 20.1. |
| Minimum | `>=16` | Версия 16 или новее. |
| Range | `>=18 <21` | Версия 18 или новее, но младше 21. |
| Wildcard | `18.x` | Любой релиз в линейке 18.x. |
| Any | `*` | Любая версия. |
| Exact | `24.1.0` | Только указанный релиз. |
